# Midnight Learning Dashboard design contract

Use this as the visual identity for deep learning dashboards.

## Mood
- Dark comfort theme for long reading.
- Premium technical dashboard, not a generic blog.
- Calm, high-contrast, ADHD-friendly.
- Visual hierarchy must guide the eye.

## Color tokens
- Background: `#0f172a`, `#111827`, `#0b1020`.
- Panel: `rgba(17,28,51,.95)` and `rgba(11,18,36,.95)`.
- Card: `rgba(15,23,42,.75)`.
- Border: `rgba(148,163,184,.18)`.
- Text: `#f8fafc` primary, `#cbd5e1` secondary, `#94a3b8` quiet.
- Accent: cyan `#38bdf8`, violet `#a78bfa`.
- Status: green `#22c55e`, yellow `#f59e0b`, red `#ef4444`.

## Layout
- Max content width: around `1180px`.
- Use a sticky top nav for long pages.
- Use generous spacing; never cram cards.
- Radius: `18px` to `24px`.
- Shadows: soft and dark; avoid harsh outlines.
- Use responsive grids with one-column mobile fallback.

## Typography
- Use system fonts only.
- Large compressed hero heading with tight line height.
- Short body paragraphs.
- Strong section titles with one visual icon/emoji anchor.
- Tables use small uppercase headers.

## Components
- Hero: big thesis, short lead, chips, start buttons.
- Scorecards: small numbers or labels in 2x2 grid.
- Cards: one idea per card.
- Concept maps: two-column, hub-spoke, or lane model.
- Flows: numbered steps, short text.
- Decision guide: green/yellow/red.
- Timeline: vertical line with dated items.
- Details blocks: dense explanation hidden by default.
- Quiz: reveal answer interaction.

## Accessibility
- Maintain high contrast.
- Do not rely only on color; include labels/icons.
- Use readable font sizes.
- Respect mobile layout.
- Include print styles.
