# Component library

Use these components to convert dense content into a learning dashboard.

## Navigation
- `sticky-nav`: top jump bar with short labels.
- `tab-strip`: in-page tabs for learning lanes.
- `start-buttons`: two or three links to important sections.

## Summary components
- `hero`: title, thesis, badges.
- `scorecard`: 4-6 tiny cards for the fastest summary.
- `pillrow`: chips for key categories.
- `callout`: strong summary or rule.

## Understanding components
- `snapshot-grid`: 3 cards for what changed / why matters / risk.
- `concept-map`: two-column, hub-and-spoke, or layered map.
- `flow`: numbered process steps.
- `lane`: parallel responsibilities or phases.
- `timeline`: dates, releases, lifecycle, roadmap.

## Comparison components
- `compare-table`: only for compact keywords and short phrases.
- `compare-cards`: use when comparison needs prose.
- `traffic-guide`: green/yellow/red decisions.
- `risk-matrix`: likelihood vs impact using cards.

## Memory components
- `details`: collapsible deep explanation.
- `quiz-reveal`: clickable reveal answer.
- `flashcards`: small memory hooks.
- `what-to-remember`: final sticky takeaway.

## Code and DevOps components
- `file-map`: important files and why they matter.
- `control-data-plane`: architecture split.
- `input-process-output`: pipeline view.
- `failure-modes`: blast radius and mitigations.
- `validation-checklist`: tests and verification.
- `rollback-card`: rollback decision and steps.
