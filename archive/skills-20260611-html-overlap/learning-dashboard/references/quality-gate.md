# Quality gate

Before returning any dashboard, check these items.

## Learning quality
- Key answer visible in under 30 seconds.
- Same concept shown in at least 3 formats.
- Dense text hidden behind details/tabs.
- Quiz or memory hook present.
- Clear next action or decision guide present.

## Visual quality
- Dark comfort theme applied.
- Sticky top nav works.
- Cards have enough spacing.
- Tables are narrow and readable.
- Mobile layout works.
- Print CSS exists.

## Technical quality
- HTML starts with `<!doctype html>`.
- No external dependencies by default.
- Inline CSS and minimal JS.
- Section IDs match nav links.
- File name is lowercase and descriptive.

## Codex quality
- If generated in a repo, output goes to docs or `.codex/output` unless user specified a path.
- No unrelated source code changes.
- Mention generated output path in final response.
