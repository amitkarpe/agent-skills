# Bundled Fallback Icon Manifest

The files under `assets/fallback-icons/` are retained only so the generator and validators can be tested without network access. They originated in the uploaded skill and are not asserted to match the latest official AWS quarterly icon package.

Production diagrams must first run `scripts/prepare_aws_icons.py` and resolve AWS services through the resulting official `catalog.json`.

`sonatype-nexus-iq.png` is a non-AWS vendor asset from a user-supplied Sonatype Help URL. Confirm redistribution and brand-use rights before public distribution.
