# Worker Goal Template

Use the canonical [goal file shape](../SKILL.md#goal-file-shape) and its
preparation gates rather than maintaining a second template here.

Supply exact approved goal, result and marker paths and a verified worker mapping;
never derive them from a lane nickname. Preserve the owning SPEC, approval,
stop conditions and acceptance/retention requirements. Missing input is a blocker,
not permission to invent a goal or dispatch work.
