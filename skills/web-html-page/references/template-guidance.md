# Web HTML Page Template Guidance

## Purpose

Use this reference only when generating the small HTML report template.

## Required sections

- Header: title, repo, lane, timestamp, status.
- TL;DR: 3-6 bullets.
- Summary cards: changed, tested, risk, next action.
- Evidence: compact checks table or short command output summary.
- Timeline: only if there are 3 or more meaningful events.

## Visual style

- One compact page.
- Inline CSS only.
- No external assets.
- Use status colors: success, warning, error, neutral.
- No tabs, no global search, no dashboards.

## Recommended emojis

- 🎯 objective
- ✅ success
- ⚠️ risk
- 🧪 evidence
- 🧭 next action
- 🕒 timeline
