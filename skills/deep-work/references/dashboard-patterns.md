# DD Deep Work Dashboard Patterns

## Core components

Use the smallest set that creates deep understanding:

- Hero thesis and 30-second view.
- Sticky nav with separate utility row.
- Snapshot cards.
- Concept map.
- Workflow or lifecycle.
- Decision guide.
- Collapsible deep dives.
- Glossary.
- Flashcards and reveal quiz.
- What-to-remember panel.

## Theme standard

- Midnight default.
- Contrast optional through compact icon-only toggle.
- Do not add many themes unless explicitly asked.

## Search standard

- Global search can be included for large dashboards.
- Card filter can be included for dense card grids.
- Keep search separate from top navigation so it never blocks section tabs.

## CommandBlock standard

Use a command card with:

- Purpose.
- Copy button that copies only the actual command.
- Command body without a shell prompt prefix.
- Expected output in a separate block.
- Warning or prerequisites when needed.
